FUSE uses Semantic Versioning with Git tags prefixed by "v".

Before v1.0.0, minor releases represent planned feature milestones:

* v0.1.0: initial proof of concept
* v0.2.0: visual model construction
* v0.3.0: port linking and compatibility
* v0.4.0: save/load and validation
* v0.5.0: full SST JSON export

Patch releases, such as v0.2.1, are used for bug fixes that do not add major new planned functionality.

The application version is defined in the build configuration and displayed in Help → About FUSE.

Jira Fix versions, GitHub release tags, and application version values should match for each release.
