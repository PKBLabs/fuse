# FUSE v0.6.0 Release Notes Draft

FUSE v0.6.0 focuses on component-catalog usability and model-view navigation. The goal is to make larger editable models easier to browse, organize, inspect, and navigate without changing simulator-specific export contracts.

## Highlights

### Component catalog preferences

Project Settings now stores user-facing catalog defaults:

- Preferred Component Sorting Mode
- Preferred Component Grouping Mode
- Auto Expand All Component Tree
- Expand/Collapse All state

When a selected model component activates a compatibility-focused catalog view, clearing the selection returns the catalog to the project's preferred grouping and sorting behavior.

### Catalog search and tree expansion

The component catalog now includes a search field above the tree. Search filters known components by metadata such as component name, display name, element/library, category, function, description, interface, plugin ID, target label, and framework version.

The Expand/Collapse All checkbox expands or collapses all levels of the component tree and persists its state with the project.

### Floating model-view toolbar

The model view now has a floating, draggable toolbar with:

- Select/Move mode
- Multiselect rectangular marquee mode
- Undo and Redo
- Zoom percentage selector
- Zoom In and Zoom Out

Toolbar position is clamped to the visible model view and persists in the `.fse` editor state.

### Zoom, panning, and grid

The model view now supports zooming with toolbar controls, explicit zoom percentages, mouse wheel events, and keyboard shortcuts. Empty-background dragging pans the visible model area, while dragging a component still moves only that component. A light grid is drawn behind the model as an organization aid.

### Editor-state persistence

The `.fse` editor block now stores model-view state such as zoom percentage, interaction mode, toolbar position, and view center. This restores the editing workspace when a project is reopened while keeping simulator model data separate from editor-only state.

### Zoom-aware hit testing

Core tests cover component, port, and link selection while zoomed in or out. Ports are prioritized near link endpoints so link geometry does not prevent practical port selection.

## Known limitations

- The grid is visual only; there is no snap-to-grid behavior yet.
- Mouse wheel zoom currently consumes wheel events in the model view rather than scrolling the scene.
- Floating toolbar placement is persisted per project but not globally shared across projects.
- Catalog search is metadata-based and depends on the quality/completeness of imported plugin metadata.
