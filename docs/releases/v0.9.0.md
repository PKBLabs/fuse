# FUSE v0.9.0 release notes draft

FUSE v0.9.0 is the v1.0 preparation release. The focus is release readiness, documentation, packaging, CI hardening, and project workflow.

## Highlights

- Documentation build checks.
- Generated API documentation configuration.
- Release and packaging workflow scaffolding.
- PyInstaller packaging spec.
- Structured GitHub issue forms.
- Expanded pull request template.
- Maintainer workflow for GitHub/Jira coordination.
- Public roadmap guidance.

## Deferred

In-app creation of new SST and gem5 component definitions is deferred to a future major release, likely v2.0.0 or later.

## Known limitations

- Packaged app artifacts may require platform-specific fixes before v1.0.
- macOS packaging is experimental until signing/notarization is defined.
- Live SST/gem5 validation still depends on local or remote simulator toolchains.
