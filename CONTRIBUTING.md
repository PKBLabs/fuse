# Contributing to FUSE

Thank you for your interest in contributing to Flexible User-extensible
Simulation Editor (FUSE).

FUSE is developed by PKB Research Labs, LLC as a maintainer-led open-source
project. Community involvement is welcome, but all changes are reviewed and
approved by the project maintainer before being merged.

## Ways to contribute

You can contribute by:

- Reporting bugs.
- Requesting features.
- Suggesting design improvements.
- Improving documentation.
- Submitting pull requests.
- Providing examples, templates, or model-generation test cases.
- Testing FUSE with SST, gem5, Simulink, or other modeling and simulation tools.

## Pull request requirements

Pull requests should:

- Clearly describe the purpose of the change.
- Reference related issues when applicable.
- Include tests where reasonable.
- Avoid unrelated formatting or style churn.
- Avoid introducing new dependencies without discussion.
- Preserve compatibility with the project license and third-party licenses.
- Include documentation updates when behavior changes.

## Branch policy

The `main` branch is the stable release branch.

The `develop` branch is the integration branch for upcoming releases.

Direct pushes to `main` and `develop` are restricted. Changes must be submitted
through pull requests and approved by the maintainer before merging.
