Detailed Description

Generate simple gem5 Python configuration scripts from FUSE scenes.

The exporter is intentionally conservative: it writes readable Python that
instantiates supported gem5 objects, applies common parameters, and emits port
connection statements where enough metadata is available.

str fuse.plugins.community.gem5.export_python.build_gem5_python (   scene) 
Build a gem5 Python configuration from a gem5-only FUSE scene.

The exporter intentionally targets the subset of gem5 SimObjects currently
exposed by the community gem5 plugin. It produces an editable Python config
rather than replacing FUSE's native .fse project format.
