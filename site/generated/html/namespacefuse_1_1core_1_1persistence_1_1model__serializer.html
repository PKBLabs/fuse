Detailed Description

Project-file schema normalization and validation helpers.

The Qt-specific persistence code converts scenes into dictionaries, then this
module finalizes metadata and validates that the resulting document conforms to
the FUSE project-file contract. Keeping these checks separate makes the schema
usable by tests, future command-line tools, and non-Qt import/export paths.

Validate a serialized .fse project at the file-structure level.

This is intentionally independent of Qt scene objects and plugin databases.
It verifies that the saved file has the sections and references needed to
reconstruct a FUSE model before the loader starts creating graphics items.
Plugin-specific export validity remains the responsibility of model/export
validation.
